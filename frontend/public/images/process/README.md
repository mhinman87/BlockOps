# Process Flow Images

This folder contains images for the animated "Our Process" section.

## Required Images

Upload these 5 PNG images with transparent backgrounds:

1. **`contact-website.png`** - Person at computer exploring medical website
   - Style: Flat, modern illustration
   - Size: 800x600px or 1000x750px
   - Colors: Teal/blue tones matching hospital.png

2. **`outreach-communication.png`** - Communication channels (phone, email, chat)
   - Multiple communication icons/illustrations
   - Shows phone, email, and chat bubble

3. **`schedule-calendar.png`** - Calendar with appointment scheduling
   - Calendar illustration with appointment slot
   - Professional medical setting theme

4. **`first-meeting.png`** - Professional consultation scene
   - Could show laptop with analytics, survey/checklist, or consultation
   - Conveys "comprehensive review" feeling

5. **`pricing-contract.png`** - Transparent pricing document/chart
   - Document or contract with dollar sign
   - Transparent pricing chart or breakdown
   - Conveys trust and clarity

## Placement

Images will appear beside hexagons (alternating left/right) as users scroll through the process flow.
