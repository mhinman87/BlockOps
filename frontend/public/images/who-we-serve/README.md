## Image Specifications

- **Format**: PNG or JPG (WebP recommended for web optimization)
- **Aspect Ratio**: 16:9 (landscape) works best
- **Recommended Size**: 800x450px to 1200x675px
- **File Size**: Keep under 300KB when possible
- **Style**: Professional medical/healthcare imagery that matches the hospital image
